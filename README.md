## Featured engineering work

### [CodeFlow AI](https://github.com/AzmanIstiaq/CodeFlow-AI)

A development-stage visual page builder for rapidly composing website layouts and exporting the active page as a runnable Next.js project.

- Built with React, TypeScript, React Flow, ASP.NET Core, and SQLite
- Supports nested rows and columns, drag-and-drop editing, inspector controls, multi-page editing state, undo/redo, and persisted site schemas
- Validates layout structure before generating and downloading a Next.js project ZIP

[Repository](https://github.com/AzmanIstiaq/CodeFlow-AI) · [Engineering case study](https://github.com/AzmanIstiaq/CodeFlow-AI/blob/main/CASE_STUDY.md)

### [NovaCMS](https://github.com/AzmanIstiaq/NovaCMS)

A full-stack content workflow application for small publishing teams that need controlled drafting, review, approval, and publishing.

- Built with React, Node.js, Express, MongoDB, and Mongoose
- Enforces JWT authentication, record ownership, and admin/editor/viewer permissions at the API boundary
- Implements explicit draft, review, publish, archive, and restore transitions with focused policy tests

[Repository](https://github.com/AzmanIstiaq/NovaCMS) · [Engineering case study](https://github.com/AzmanIstiaq/NovaCMS/blob/main/CASE_STUDY.md) · [Deployment](https://nova-cms.vercel.app/)

### [EventHub](https://github.com/AzmanIstiaq/EventHub)

A collaborative RMIT team project for managing and discovering events, built by a six-person group with Spring Boot, MySQL, Docker, and role-based user flows. My individual contribution should be read in the context of the shared team repository rather than as sole authorship.
